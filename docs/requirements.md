## 2. 项目概述

- **产品**：面向小学一年级、二年级的学习网站。
- **目标用户**：小学一、二年级学生（及家长/老师组织练习）。
- **科目**：数学、语文、英语的学习、复习和练习。
- **交付策略**：Phase 1 数学已完成；**Phase 2 首页 + 英语开发中**（英语内容已整理入 `data/textbooks.json`）；Phase 3 语文（数据已就绪，待排期）。
- **全局约束**：苹果风主题；尽量使用开源免费技术；在本地可运行。

## 4. 全局/跨科目需求（三个科目共用的模式）

以下能力在数学（Phase 1）中实现，设计上应可被语文、英语（Phase 2）复用：

| 编号 | 需求 | 说明 |
|------|------|------|
| G-01 | 苹果风主题 | UI 采用苹果设计风格（见 NFR-01） |
| G-02 | 本地可运行 | 无需部署服务器，本地即可运行使用 |
| G-03 | 开源免费技术 | 技术选型尽量使用开源、免费方案 |
| G-04 | 答题模式 | 支持输入答题、四选一答题；答完自动判题并进入下一题；答错给出解题思路 |

## 5. Phase 1 数学详细需求

### 5.1 需求清单

#### FR-MATH-01 加法
- **描述**：支持 10 以内、20 以内、50 以内、100 以内加法出题。
- **验收标准**：
  - [ ] 可选择"10 以内 / 20 以内 / 50 以内 / 100 以内"任一档位出题。
  - [ ] 任一档位下，两数之和不超过该档位上限（如 20 以内：和 ≤ 20）。
  - [ ] 两加数均为非负整数，且符合档位约束。

#### FR-MATH-02 减法
- **描述**：支持 10 以内、20 以内、50 以内、100 以内减法出题。
- **验收标准**：
  - [ ] 可选择"10 以内 / 20 以内 / 50 以内 / 100 以内"任一档位出题。
  - [ ] 结果为非负整数（不出现负数答案），被减数符合档位上限。
  - [ ] 档位、操作数可与 FR-MATH-07（操作数选择）组合配置。

#### FR-MATH-03 乘法
- **描述**：支持 9×9 以内乘法出题。
- **验收标准**：
  - [ ] 两个乘数均在 1 ~ 9 范围内。
  - [ ] 可与 FR-MATH-07（操作数选择）组合配置。

#### FR-MATH-04 除法
- **描述**：支持 9×9 以内除法出题。
- **验收标准**：
  - [ ] 被除数、除数在 9×9 范围内，且结果为整除（无余数）。
  - [ ] 除数不为 0。
  - [ ] 可与 FR-MATH-07（操作数选择）组合配置。

#### FR-MATH-05 换算
- **描述**：支持单位换算题，覆盖以下类别：
  - 时间：小时、分、秒
  - 长度：千米、米、分米、厘米、毫米
  - 重量：千克、克、毫克、微克
  - 体积：（单位待确认，见 Q-01）
  - 温度：（单位：摄氏度等，待确认，见 Q-01）
- **验收标准**：
  - [ ] 可选择上述任一类别出换算题。
  - [ ] 同一类别内换算单位取自该类别的单位清单。
  - [ ] 换算结果按正确进率计算，答案唯一正确（方向/进率规则见 Q-03）。

#### FR-MATH-06 混合练习
- **描述**：支持从加法、减法、乘法、除法、换算中选择运算类型进行混合出题；运算类型的选择支持**单选和多选**。
- **验收标准**：
  - [ ] 可只选一种运算类型（单选）。
  - [ ] 可同时选中多种运算类型（多选），题目按选中类型混合生成。
  - [ ] 至少选择一种类型才能开始练习。

#### FR-MATH-07 操作数选择（原文"位数"）
- **描述**：减法、乘法、除法可选择参与出题的操作数——即可勾选哪些操作数参与随机出题、哪些被固定（例如：固定除数、随机被除数；固定减数、随机被减数等）。
- **验收标准**：
  - [ ] 减法题可配置"被减数、减数"各自是随机生成还是固定值。
  - [ ] 乘法题可配置"被乘数、乘数"各自是随机生成还是固定值。
  - [ ] 除法题可配置"被除数、除数"各自是随机生成还是固定值。
  - [ ] 固定值由用户在出题设置中指定；被固定的数在整套题中保持不变。
  - [ ] 该配置与 FR-MATH-01 ~ FR-MATH-04 的范围约束同时生效（固定值必须落在所选范围内，否则给出校验提示）。

#### FR-MATH-08 题数
- **描述**：一次练习的题数可选择 10、20、50 道。
- **验收标准**：
  - [ ] 提供 10 / 20 / 50 三档题数选项。
  - [ ] 一次练习实际生成的题目数与所选题数一致。

#### FR-MATH-09 答题与自动判题
- **描述**：支持**输入答题**与**四选一答题**两种方式；每题作答完成后自动判题并自动进入下一题。
- **验收标准**：
  - [ ] 可在输入答题与四选一之间切换（配置在练习前或练习中，见 Q-08）。
  - [ ] 输入答题：学生输入答案，提交后立即判定对错。
  - [ ] 四选一答题：题目给出 4 个选项，选择后立即判定对错（干扰项来源见 Q-04）。
  - [ ] 判题后无需手动操作即自动进入下一题（或明确的"继续"动作，见 Q-08）。
  - [ ] 最后一题判题后进入结果统计页。

#### FR-MATH-10 解题思路
- **描述**：答题错误后，给出该题的解题思路。
- **验收标准**：
  - [ ] 每道答错的题都会展示解题思路。
  - [ ] 解题思路与题型匹配（加/减/乘/除/换算各自有对应思路，生成方式见 Q-05）。
  - [ ] 答对的题不强制展示解题思路。

#### FR-MATH-11 A4 打印
- **描述**：支持将练习题打印为 A4 纸张格式。
- **验收标准**：
  - [ ] 提供打印入口，打印布局按 A4 页面适配（分页正确、不截断题目）。
  - [ ] 打印内容包含题目本身；是否含答案页见 Q-07。
  - [ ] 打印不依赖联网服务（浏览器本地打印）。

#### FR-MATH-12 计时与耗时分析
- **描述**：答题阶段对每道题单独计时；答题完成后统计总耗时，并对耗时进行分析。
- **验收标准**：
  - [ ] 每道题从展示到提交的耗时被单独记录。
  - [ ] 练习完成后展示本次总耗时。
  - [ ] 提供耗时分析（分析维度与呈现形式见 Q-06）。
  - [ ] 切到后台/离开页面时的计时规则见 Q-09。

#### FR-MATH-13 易错收藏与专项练习
- **描述**：每次答错的题自动统计并进入易错收藏；支持针对易错题的专项答题。
- **验收标准**：
  - [ ] 每次练习中答错的题自动加入易错收藏（去重规则见 Q-10）。
  - [ ] 可查看易错收藏列表。
  - [ ] 可从易错收藏发起"易错题专项答题"，流程复用 FR-MATH-09 ~ FR-MATH-12。
  - [ ] 专项答题中再次答错仍会保留在易错收藏中。

#### FR-MATH-14 去重（尽可能不重复）
- **描述**：出题时尽可能不重复。
- **验收标准**：
  - [ ] 同一次练习内不出现重复题目。
  - [ ] 跨练习的去重范围见 Q-11。

## 5A. Phase 2 首页 + 英语详细需求（本期开发）

### 5A.0 数据现状（已核实，2026-10-06）

英语内容已整理完成，位于 `data/textbooks.json` → `english`（来源：新交际英语 2024，外研社，北京市义务教育）：

| 维度 | 现状 |
|------|------|
| 覆盖 | 一/二年级 × 上册/下册 × 每册 6 单元 = 24 单元 |
| 单词 | **302 条**，字段 `{ en, zh, unverified? }`（unverified 仅 2 条） |
| 语句 | **357 条**，字段 `{ en, zh, zh_note?, source? }`（zh_note 68 条，为中文注释） |
| 音标 | **数据中无音标字段** → 构建期增强，见 FR-ENG-08 |
| 句法 | **数据中无句法标注** → 构建期 spaCy 预计算，见 FR-ENG-13 |

> 注意：单词池按单元规模差异大（5～28 词），单词练习题数必须做题池上限约束，见 FR-ENG-09。

### 5A.1 首页

#### FR-HOME-01 首页与科目入口
- **描述**：首页为站点唯一入口页，提供语文、数学、英语三个科目的练习入口卡片。
- **验收标准**：
  - [ ] 默认打开站点即首页（hash 路由 `#/`）。
  - [ ] 展示语文、数学、英语三张科目卡片，各含科目名、科目描述/练习简介、进入按钮。
  - [ ] 数学卡片进入现有数学口算流程，既有功能零回归（配置→答题→统计→易错→打印）。
  - [ ] 英语卡片进入英语模块首页（单词练习 / 语句练习 两个子入口）。
  - [ ] 语文卡片进入语文占位页（明确"即将上线"提示；Phase 3 前不开发练习功能）。
  - [ ] 支持浏览器前进/后退（hash 路由）。
  - [ ] 苹果风：大留白、居中标题、圆角卡片、悬停微动效、科目主题色区分（NFR-01）。

### 5A.2 英语 — 单词练习

#### FR-ENG-01 单词练习筛选
- **描述**：按年级、学期、单元筛选单词题池，支持**单选和多选**。
- **验收标准**：
  - [ ] 提供年级（一/二年级）、学期（上册/下册）、单元（1～6）三组筛选器。
  - [ ] 每组筛选器内支持单选与多选（可多选单元）。
  - [ ] 筛选结果实时显示命中题池的单词数。
  - [ ] 题池为空时禁用"开始练习"并给出提示。

#### FR-ENG-02 中英文单词练习
- **描述**：支持两个方向的中英互选：出中文选英文、出英文选中文。
- **验收标准**：
  - [ ] 模式"英→中"：题面为英文单词，答案为其中文释义。
  - [ ] 模式"中→英"：题面为中文释义，答案为英文单词。
  - [ ] 两种方向均支持四选一与键盘输入两种作答（手写见 FR-ENG-04）。

#### FR-ENG-03 英文单词听写
- **描述**：网站使用 TTS 朗读单词，学生听音后回答单词。
- **验收标准**：
  - [ ] 题面不显示英文单词，仅通过 TTS 发音（附"重播"按钮）。
  - [ ] 学生以键盘输入或手写作答，判题对英文大小写不敏感、忽略首尾空格。
  - [ ] 答错后展示该单词（含中文释义、音标）与发音，作为提示。

#### FR-ENG-04 答题方式（四选一 / Canvas 手写 OCR / 键盘输入）
- **描述**：支持三种答题方式：四选一、网页 Canvas 书写并 OCR 识别、键盘输入。
- **验收标准**：
  - [ ] 可在配置页选择三种答题方式之一。
  - [ ] 四选一：3 个干扰项 + 1 正确项，干扰项取自同筛选范围内其它单词（同方向）。
  - [ ] Canvas 手写：提供书写区、清空按钮；提交时用 OCR 识别手写内容并判题；识别置信/结果可确认。
  - [ ] OCR 资产本地可用（离线可运行，见 NFR-02）；OCR 不可用时自动降级为键盘输入并提示。
  - [ ] 键盘输入：文本框输入，回车提交，立即判题。

#### FR-ENG-05 A4 打印
- **描述**：单词练习支持 A4 打印（复用 G-06）。
- **验收标准**：
  - [ ] 提供打印入口，A4 分页、题目不截断。
  - [ ] 提供含答案/不含答案两版。

#### FR-ENG-06 计时与耗时分析
- **描述**：复用 G-07：每题计时、总耗时统计与耗时分析。
- **验收标准**：
  - [ ] 每题单独计时，切后台暂停。
  - [ ] 练习完成展示总耗时、每题耗时列表、最慢/最快/平均。

#### FR-ENG-07 易错收藏与专项练习
- **描述**：复用 G-08：答错自动进入易错收藏，支持易错专项答题。
- **验收标准**：
  - [ ] 答错单词自动入收藏（按指纹去重累计次数）。
  - [ ] 可查看、移除；可发起易错专项练习（复用答题流程）。

#### FR-ENG-08 音标标注
- **描述**：单词展示音标（数据无音标 → 构建期增强）。
- **验收标准**：
  - [ ] 练习界面（题面、反馈、易错列表）在单词有音标时展示 IPA 音标。
  - [ ] 无音标的单词优雅降级（不展示音标区，不报错）。
  - [ ] 音标来源于构建期开源词典数据增强脚本（离线并入数据，运行时不依赖网络）。

#### FR-ENG-09 题数与去重
- **描述**：题数可选 10、20、50（G-05）；出题尽可能不重复（G-09）。
- **验收标准**：
  - [ ] 提供 10/20/50 三档。
  - [ ] **实际题数 = min(所选题数, 题池大小)**；题池不足时提示"题池仅 N 题"。
  - [ ] 单次练习内题目严格不重复；跨练习优先出未做过的单词。

### 5A.3 英语 — 语句练习

#### FR-ENG-10 语句练习筛选
- **描述**：按年级、学期、单元筛选语句题池，单选和多选。
- **验收标准**：同 FR-ENG-01（作用于语句池）。

#### FR-ENG-11 中英文短语/语句互译
- **描述**：支持英文句子翻译中文、中文翻译英文两个方向。
- **验收标准**：
  - [ ] 模式"英→中"：题面英文句子，作答中文（键盘输入；判题采用归一化宽松匹配，见 Q-ENG-05）。
  - [ ] 模式"中→英"：题面中文，作答英文（键盘输入；大小写/标点/空格归一化）。
  - [ ] 四选一作答同样可用（选项为完整句）。

#### FR-ENG-12 英文语句 TTS 发音与跟读、中英对照
- **描述**：TTS 发音英文语句，学生跟读，支持中英文对照练习。
- **验收标准**：
  - [ ] 提供"播放"按钮朗读英文句子，可重播。
  - [ ] 跟读模式：播放后学生跟读，可调速（慢速/常速）；进入下一题前展示参考音频重播。
  - [ ] 作答/反馈阶段提供中英对照（英文 + 中文 + zh_note 注释如有）。

#### FR-ENG-13 语句结构标注（spaCy 预计算）
- **描述**：对语句做句法分析，标记主谓宾、状语、定语、形容词等成分。

## 9. 假设（Assumptions）

1. **数学题目为算法生成**：口算、换算题均由程序随机生成，无需维护数学题库内容（区别于语文、英语依赖教材内容）。
2. **单用户本地使用**：无账号、登录、多用户系统；数据存于本机浏览器。
3. **"9×9 以内乘法/除法"** 指参与运算的两个数均不超过 9；除法为整除、无余数。
4. **减法不出负数**：所有减法题被减数 ≥ 减数。
5. **"10/20/50/100 以内"** 指题中数值（和/差或参与运算的数）不超过对应上限，具体判定口径在开发前可再确认。
6. **UI 语言为简体中文**。
7. **打印为练习题卷**（学生作答用），是否附答案见 Q-07。
